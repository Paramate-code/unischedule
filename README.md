# Django 

โปรเจกต์นี้เป็นระบบจัดการผู้ใช้ที่พัฒนาด้วย Django Framework ซึ่งมีฟีเจอร์หลักเกี่ยวกับการจัดการบัญชีผู้ใช้ เช่น การลงทะเบียน การเข้าสู่ระบบ และการจัดการข้อมูลโปรไฟล์ พร้อมระบบเก็บภาพโปรไฟล์

pip install django
รัน Migration และสร้าง Superuser

python manage.py migrate
python manage.py createsuperuser
รันเซิร์ฟเวอร์

python manage.py runserver
เข้าใช้งานระบบได้ที่: http://127.0.0.1:8000

ฟีเจอร์ที่มีในระบบ
ระบบ Login / Register

การจัดการโปรไฟล์ผู้ใช้
ระบบจัดเก็บภาพโปรไฟล์ลงใน media/profile_pictures
การแยกแอป myapp สำหรับจัดการผู้ใช้
